EcoTrack - A Smart Waste Management & Recycling Ecosystem

Tagline: Modernizing urban waste collection through real-time logistics and data-driven insights.
Project Overview: EcoTrack is a comprehensive waste management platform designed to bridge the gap between households (Recyclers), collection services (Drivers), and management (Admin). The ecosystem consists of a high-performance Android mobile application and a feature-rich web-based administration dashboard, ensuring seamless coordination and efficiency in the recycling process.
Key Features:

•	♻️ Recycler Experience: User-friendly mobile interface to schedule pickups, track collection status in real-time, manage subscription plans, and access educational content on sustainable living.

•	🚚 Driver Logistics: Dedicated driver portal for route optimization, real-time navigation, earnings tracking, and digital verification of waste collection.

•	📊 Admin Control Center: Centralized web dashboard for orchestrating the entire system—managing users and drivers, monitoring analytics, planning logistical routes, and handling emergency responses.

•	🗺️ Real-time Tracking: Map integration for live location updates and efficient dispatching.

Tech Stack:

•	Mobile: Java/Kotlin (Android SDK), SQLite, Firebase.

•	Web Frontend: React, TypeScript, Vite, Tailwind CSS, Shadcn UI.

•	Backend/Services: Firebase (Authentication, Firestore, Cloud Functions).

•	Visualization: Recharts for data analytics and Leaflet for geospatial tracking.

EcoTrack Admin | Intelligent Logistics & Management Dashboard

Overview: The EcoTrack Admin Web Portal is the central nervous system of the recycling ecosystem. Built with a focus on speed, scalability, and intuitive UX, it provides administrators with the tools necessary to monitor urban waste collection and manage the workforce effectively.
Core Modules:

•	User & Driver Intelligence: Advanced management tools for onboarding drivers, verifying recycler accounts, and managing role-based permissions.

•	Dynamic Dispatch & Routing: Interactive route planning module utilizing map services to optimize collection paths and reduce fuel consumption.

•	Pickup & Subscription Engine: Comprehensive management of scheduled pickups and user subscription tiers, integrated with billing and status updates.

•	Actionable Analytics: Real-time data visualization through Recharts to monitor collection efficiency, driver performance, and recycling trends.

•	Emergency & Priority Response: Specialized dashboard for handling urgent collection requests and operational issues in real-time.

Technical Highlights:

•	Development Environment: Vite + TypeScript for a blazing-fast, type-safe developer experience.

•	Architecture: Component-driven design using React and Tailwind CSS, following modern "Shadcn" UI patterns for a premium look and feel.

•	State & Data: Integrated with Firebase Firestore for real-time data syncing and React Query for efficient server state management.

•	PDF & Reports: Capability to generate and export reports using jspdf and html2canvas.
