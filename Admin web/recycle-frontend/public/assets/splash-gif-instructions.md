# Splash Screen GIF Instructions

## How to Add Your GIF to the Splash Screen

### 1. File Placement

Save your GIF file as: `public/assets/splash-animation.gif`

### 2. File Requirements

- **Format**: GIF (animated)
- **File Name**: `splash-animation.gif` (exact name required)
- **Location**: `public/assets/splash-animation.gif`
- **Recommended Size**: 400x300px or similar aspect ratio
- **File Size**: Keep under 2MB for optimal loading

### 3. What the Splash Screen Does

- **First Page**: Users see this when they visit your site
- **Loading Animation**: Shows for 2 seconds with spinning icon
- **GIF Display**: Your GIF appears after loading
- **Navigation**: Users can click "Get Started" or "Skip Introduction" to go to login

### 4. Fallback Behavior

If the GIF file doesn't exist, the splash screen will show:

- A placeholder with recycling icon
- Instructions on where to place the GIF file
- Still fully functional navigation

### 5. Testing

1. Save your GIF as `public/assets/splash-animation.gif`
2. Start the development server: `npm run dev`
3. Visit: `http://localhost:5174/`
4. You should see your GIF in the splash screen

### 6. Customization

The splash screen includes:

- Beautiful gradient background
- Professional card layout
- Responsive design
- Smooth animations
- Feature highlights
- Easy navigation to login

### 7. Navigation Flow

- `/` → Splash Screen (with your GIF)
- `/admin/login` → Admin Login Page
- `/dashboard` → Main Dashboard (after login)

Your GIF will be the first thing users see when they visit your Eco Track system!
